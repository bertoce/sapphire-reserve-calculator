# Sapphire Reserve ROI Calculator

A modern, minimalist calculator to analyze whether the Chase Sapphire Reserve credit card annual fee is worth it based on your personal spending patterns and benefit usage.

## Features

- **Annual Spending Analysis**: Track spending across different point multipliers
- **Benefit Optimization**: Calculate value from travel credits, dining credits, and service benefits
- **High Spender Benefits**: Unlock premium perks for $75k+ annual spending
- **Real-time ROI**: Live calculation with clear recommendation
- **Minimalist Design**: Clean, geometric interface inspired by modern art

## Built With

- React 18
- Tailwind CSS
- Lucide React Icons
- Deployed on Vercel
